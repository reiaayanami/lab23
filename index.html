Коротко про GNU/Linux

GNU/Linux — це сімейство вільних операційних систем, які поєднують ядро Linux із системними утилітами та бібліотеками проєкту GNU.

Ядро Linux у 1991 році створив фінський студент Лінус Торвальдс. Проєкт GNU, започаткований Річардом Столменом у 1983 році, на той час уже мав компілятор, командну оболонку та інші інструменти, але не мав власного ядра. Разом вони утворили повноцінну систему. Код поширюється за ліцензією GPL, тому його можна вільно запускати, вивчати, змінювати й розповсюджувати.

Ядро відповідає за пам’ять, процеси та пристрої. Користувач взаємодіє із системою через графічне середовище (GNOME, KDE Plasma, Xfce) або через термінал і командну оболонку, найчастіше — Bash.

Приклади команд у Linux CLI

Нижче — десять базових команд. Рядок, що починається з $, вводить користувач, решта — відповідь системи.

pwdprint working directory

Показує повний шлях до поточного каталогу.

$ pwd
/home/student

echoвивід тексту

Виводить рядок або значення змінної. Разом із > записує текст у файл.

$ echo "Привіт, Linux!"
Привіт, Linux!
$ echo $HOME
/home/student
$ echo "перший рядок" > note.txt

lslist

Показує вміст каталогу. Корисні ключі: -l — докладний список, -a — разом із прихованими файлами, -h — розміри у зручному вигляді.

$ ls
Documents  Downloads  note.txt
$ ls -lah
drwxr-xr-x 5 student student 4.0K Oct  3 10:12 .
-rw-r--r-- 1 student student   26 Oct  3 10:14 note.txt

cdchange directory

Переходить в інший каталог. .. — на рівень вище, ~ — домашній каталог, - — назад у попередній.

$ cd Documents
$ pwd
/home/student/Documents
$ cd ..
$ cd ~

touchстворити файл

Створює порожній файл або оновлює час зміни наявного.

$ touch report.txt
$ ls
report.txt

mkdirmake directory

Створює каталог. Ключ -p створює вкладені каталоги за один раз.

$ mkdir lab1
$ mkdir -p projects/linux/scripts

cpcopy

Копіює файли. Для каталогів потрібен ключ -r.

$ cp report.txt report_backup.txt
$ cp -r lab1 lab1_copy

mvmove / rename

Переміщує файл або перейменовує його.

$ mv report.txt final.txt
$ mv final.txt lab1/

rmremove

Видаляє файли. Ключ -r видаляє каталоги, -i просить підтвердження перед кожним видаленням.

$ rm report_backup.txt
$ rm -ri lab1_copy
rm: descend into directory 'lab1_copy'? y

historyісторія команд

Показує список раніше введених команд. Команду за номером можна повторити через !номер.

$ history | tail -3
  101  mkdir lab1
  102  cp -r lab1 lab1_copy
  103  history | tail -3
$ !101

Обережно з rm. У Linux немає кошика для видалених через термінал файлів. Перед командою rm -r перевіряйте шлях через pwd та ls.

BASH-скрипт: імітація авторизації

Скрипт має запитати ім’я користувача й пароль, приховати введення пароля, дати три спроби та повідомити про результат.

#!/bin/bash
# login.sh — імітація авторизації в системі у текстовому режимі

VALID_USER="student"
VALID_PASS="linux123"
MAX_TRIES=3

clear
echo "GNU/Linux $(uname -r) $(hostname) tty1"
echo

for ((try = 1; try <= MAX_TRIES; try++)); do
    read -p "$(hostname) login: " username
    read -s -p "Password: " password
    echo

    if [[ "$username" == "$VALID_USER" && "$password" == "$VALID_PASS" ]]; then
        echo
        echo "Last login: $(date '+%a %b %d %H:%M:%S %Y') on tty1"
        echo "Welcome, $username! Авторизацію виконано успішно."
        exit 0
    fi

    sleep 1
    echo "Login incorrect"
    echo
done

echo "Забагато невдалих спроб. Сеанс завершено."
exit 1
Як працює скрипт
  • read -p виводить запрошення та зчитує введений рядок у змінну.
  • read -s не показує символи під час введення, як у справжньому терміналі.
  • Цикл for обмежує кількість спроб значенням MAX_TRIES.
  • Умова [[ ... && ... ]] перевіряє одночасно ім’я та пароль.
  • exit 0 завершує скрипт після успішного входу, exit 1 — після невдалих спроб.

Запуск:

$ chmod +x login.sh
$ ./login.sh

Файл скрипта також можна завантажити: login.sh. Дані для входу в прикладі: student / linux123.
