# GNU/Linux — опрацювання теми

Навчальний проєкт: веб-сторінка з оглядом операційної системи GNU/Linux.

## Зміст сторінки

- Коротка інформація про GNU/Linux
- Найпопулярніші дистрибутиви
- Приклади команд CLI: `pwd`, `echo`, `ls`, `cd`, `touch`, `mkdir`, `cp`, `mv`, `rm`, `history`
- BASH-скрипт, що імітує авторизацію в текстовому режимі
- Джерела інформації

## Файли

| Файл | Призначення |
|------|-------------|
| `index.html` | Розмітка сторінки |
| `style.css` | Стилі |
| `login.sh` | BASH-скрипт авторизації |

## Запуск скрипта

```bash
chmod +x login.sh
./login.sh
```

Логін: `student`, пароль: `linux123`. Дається три спроби входу.
